it: Crea uno .zip da allegare a una segnalazione GitHub: questa immagine, gli ultimi log del gioco, le sue impostazioni, i salvataggi se selezionati e i dettagli del PC (Windows, scheda video, processore). Il nome utente di Windows è escluso.

en: Open GitHub Issue opens a new issue with its text filled in and copies that text too: if the page comes up empty, paste it there (Ctrl+V). Then drag the zip into the issue. Posting needs a free GitHub account.
it: Apri segnalazione GitHub apre una nuova segnalazione con il testo già compilato e copia anche quel testo: se la pagina si apre vuota, incollalo lì (Ctrl+V). Poi trascina lo zip nella segnalazione. Per pubblicare serve un account GitHub gratuito.
